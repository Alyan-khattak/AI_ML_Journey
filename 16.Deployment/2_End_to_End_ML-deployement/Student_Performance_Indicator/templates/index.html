How it works
⚙️
Modular ML pipeline
Built with production software engineering patterns — config/component separation, custom exception handling with traceback extraction, timestamped logging, and editable local package installation via pip install -e .

Each stage runs independently and passes typed outputs to the next — paths from ingestion, numpy arrays from transformation, and a serialized model from training.
scikit-learn pandas dill @dataclass GridSearchCV ColumnTransformer
🔢
Feature engineering
Median imputation for numerics, mode imputation for categoricals, one-hot encoding, and StandardScaler — fit only on train, transform on test.
🎯
Hyperparameter tuning
GridSearchCV with 3-fold CV across 9 models. Best params per model logged. Threshold check — models below R² 0.6 are rejected.
🌐
Flask prediction API
POST form data → CustomData validates → preprocessor transforms → model predicts. Preprocessor and model loaded from artifacts/ at inference time.
